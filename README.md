## 作品について

三国志演義の江戸時代の和訳。湖南文山が訳した『通俗三国志』で、首巻（姓氏）と巻之一から巻之五十までを収める。明治 44〜45 年（1911〜12 年）に早稲田大学出版部が『通俗二十一史』の第 4・5 巻（上・下）として出した。国立国会図書館の目次の字のままの見出しが付く。巻頭の例言・三国世系一覧と目次（早稲田大学編輯部）は入れていない。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
